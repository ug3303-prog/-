# 대장주 단기스윙 스캐너 v1

단타 스캐너(`danta_v16`)가 **시총 1조 넘는 대형주를 걸러내기 때문에**, 대장주를
*다른 로직*으로 치기 위한 전용 도구. SK텔레콤 같은 대형주는 소형주 단타랑
움직이는 원리가 달라서(수급 중심, 며칠 보유), 채점 기준을 새로 짰다.

## 단타 스캐너랑 뭐가 다른가

| | 소형주 단타(danta_v16) | 대장주 단기스윙(이 프로그램) |
|---|---|---|
| 시총 | 2천억~1조 | **1조 이상** |
| 동력 | 거래량 급가속(2배+) | **수급(외국인·기관·프로그램)** |
| 보유 기간 | 당일~1일 | **2~10일** |
| 추세/칼날 필터 | 20·60일선 | **120·200일선** |
| 급등 차단 | 당일 +15% | **당일 +8%** (대형주는 이게 과열) |
| 핵심 셋업 | 눌림 반등·돌파 | **정배열 속 눌림목 + 수급 전환 + 반등 확인** |

**중요:** 이 프로그램은 `danta_v16.py`를 *수정하지 않는다.* 그 안의 검증된
부품(KIS 연결·토큰·DART·ATR 손절·수량계산)을 `import`로 **재사용만** 한다.
그래서 단타 스캐너는 전혀 안 건드리고, 둘이 **같은 `kis_config.json`을 공유**한다.

## 폴더에 필요한 파일

같은 폴더(단타 스캐너 폴더에 그냥 같이 둬도 됨)에:

- `swing_v1.py` — 스윙 채점 엔진 (새로 추가)
- `SwingScanner_GUI.py` — 창 프로그램 (새로 추가)
- `run_swing.bat`, `run_swing_debug.bat` — 실행 파일 (새로 추가)
- `danta_v16.py` — **기존 단타 엔진** (이미 폴더에 있음, 부품으로 재사용)
- `kis_config.json` — **기존 KIS 키 파일** (단타 스캐너랑 공유)

## 실행

1. **`run_swing.bat` 더블클릭** → 창이 뜸
   - 안 뜨거나 바로 꺼지면 `run_swing_debug.bat`로 실행 (검은 창에 오류가 보임)
2. KIS 키가 이미 `kis_config.json`에 있으면 자동으로 채워짐.
   없으면 APP KEY / APP SECRET 입력 후 **[키 저장]**
3. **[연결 점검]** 눌러서 삼성전자 시세·일봉 200개·수급이 뜨는지 확인
4. 조건 확인하고 **[▶ 스캔 시작]**
   - 대형주 일봉을 200개씩 받느라 **첫 스캔은 2~4분** 걸릴 수 있음(당일 캐시되므로 재스캔은 빠름)

## 결과 읽는 법

**🎯 스윙 후보 탭** — 점수순. 색깔:
- 🟢 **선도매수**: 정배열 + 수급 + 눌림목 다 통과한 최우선 후보 (정원 = 보유종목수 × 2)
- 🟡 **매수대기**: 점수는 되지만 선도 자격 하나가 빠진 종목 (`선도 제외 사유` 칸 확인)
- 흰색 **관심**: 점수 미달이지만 관찰 가치

**💰 추천 포트폴리오 탭** — 자본·손익비로 수량까지 계산된 실전 표.
`손절가(자동주문)`·`목표가(자동주문)`를 **NH 시세포착 자동주문에 그대로 입력**
(호가단위 이미 맞춰져 있음).

**⛔ 차단 종목 탭** — 점수와 무관하게 매수 금지. 사유:
떨어지는 칼날(120/200일선 아래+하락), 하락추세, 당일 +8%↑ 급등, 5일 -15%↓ 급락,
악재공시(유증·CB·BW), 거래정지·투자경고 등.

## 점수 구성 (100점)

| 항목 | 배점 | 핵심 |
|---|---|---|
| ① 추세/정배열 | 25 | 현재가>5>20>60>120일선. 200일선 위 |
| ② 눌림목 위치 | 25 | 고점 대비 -3~-10% + 20/60일선 지지권 |
| ③ 수급 | 25 | **외국인·기관 3일 동반 순매수** + 프로그램 (대형주 핵심) |
| ④ 반등 확인 | 15 | 오늘 양봉 + 전일종가 돌파 + 거래량 + VWAP·체결강도 |
| ⑤ 상대강도 | 10 | 섹터 평균 대비 강세 + 5일 상승 유지 |

## 조건값 조절 (창 상단 "발굴 조건")

- **시총 하한**: 기본 10,000억(1조). 2조 이상만 보려면 20000
- **스캔 상위**: 시총 상위 몇 개를 볼지(기본 120). 늘리면 느려짐
- **선도/대기/관심 ≥**: 등급 점수 기준. 지수가 20일선 아래면 자동으로 보수화(+상향)

## 꼭 기억할 것 (중요)

- **이건 "조건 스크리닝"이지 매수 추천이 아니다.** 점수는 위 규칙의 계산값일 뿐,
  수익 보장이 아니다. 종목·금액·매수 여부는 본인 판단.
- **점수 가중치는 아직 백테스트로 검증 안 됨.** 실전 자금은 최소로 두고,
  모의/소액으로 몇 주 돌려 `대장주스윙_기록.xlsx`를 쌓은 뒤 늘려라.
- **네 손실의 대부분은 진입이 아니라 "손절 미실행"에서 나왔다.** 이 도구가 주는
  진짜 값은 `손절가(자동주문)` 칸이다 — NH 서버측 자동손절에 걸어두고 손 떼는 것.
- 장중(09:00~15:30)에 돌리면 오늘 봉이 미완성이라 거래량·이동평균은 직전 거래일
  기준으로 계산된다. **저녁/주말에 돌려 다음날 계획 세우는 용도**로도 좋다.

## 보안 주의

`kis_config.json`, `.kis_token.json`은 **API 키·토큰이 평문**으로 저장된다.
이 폴더가 **OneDrive 같은 클라우드 동기화 폴더 안에 있으면** 그쪽으로 그대로
업로드된다. 키 파일을 채팅·메신저에 붙여 넣었다면 **반드시 키를 재발급**해라.
