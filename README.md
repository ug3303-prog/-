# 주식 도구 모음 (GUI)

이 폴더엔 서로 다른 두 프로그램이 있음:

- **`gui.py`** — 대장주 자동 발굴기 (스윙용 스크리닝)
- **`scalper.py`** — 초단타 모니터링 (몇 분~몇 시간 단위 매매 참고용)

## 대장주 자동 발굴기 (`gui.py`)

`auto_finder.py`의 스크리닝 로직(대형주 + 상승추세 + 눌림 + 거래대금 + PER/PBR + DART 재무)을
Tkinter 데스크톱 GUI로 감싼 프로그램.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python gui.py
```

1. 상단에 KIS(한국투자증권) Open API `APP KEY` / `APP SECRET` 입력 (모의투자면 체크박스 선택)
2. "키 저장"을 누르면 `kis_keys.json`에 저장되어 다음 실행부터 자동 로딩됨 (git에는 커밋되지 않음)
3. DART 재무정보(부채비율, 영업이익 흑자여부 등)를 쓰려면 `DART API KEY`도 입력하고
   "DART 재무정보 사용" 체크 — 종목마다 추가 조회가 붙어 스캔이 느려짐
4. 조건(시총 상위 N개, 최소 시총, 눌림 기준 등) 확인 후 "▶ 스캔 시작"
5. 결과는 "조건 충족" / "칼날 주의(하락추세)" 표에 표시, CSV로도 저장 가능

## 초단타 모니터링 (`scalper.py`)

```bash
python scalper.py
```

**⚠️ 매수/매도 주문을 절대 넣지 않는 읽기 전용 툴입니다.** 워치리스트에 종목코드를 넣고
폴링 주기(기본 3초)마다 호가 매수/매도 잔량비, 체결강도, 거래량 급증, 급등/급락을 계산해서
표와 알림 로그로만 보여줍니다. 매수/매도는 본인이 증권사 앱에서 직접 판단해서 누르는 구조입니다.
하단의 "포지션 크기 계산기"는 투자금과 손절%를 넣으면 몇 주 살지/손절가·목표가가 얼마인지
계산해주는 참고용 계산기입니다(이것도 자동 주문 아님).

**신호 기준값**(필요하면 `scalper.py` 상단 상수를 직접 조정):
- 체결강도 150 이상 = 매수 쏠림, 70 이하 = 매도 쏠림 (100이 매수/매도 균형)
- 호가 총매수잔량/총매도잔량 1.8배 이상 = 매수우위, 0.56배 이하 = 매도우위
- 폴링 간격 사이 ±1% 이상 가격 변동 = 급등/급락 알림
- 거래량 증가분이 직전 폴링 증가분의 3배 넘으면 거래량 급증 알림

**신호 노이즈 줄이기**: 단일 신호 1개만 뜬 건 쿨다운(기본 45초)을 걸어 종목당 너무 자주
로그에 안 남게 했고, **신호 2개 이상이 같은 방향으로 동시에 뜨는 "복합 신호"만 🔥로 즉시
로그**에 남긴다. (표에는 단일 신호든 복합 신호든 항상 다 보임 — 로그만 걸러서 보여준다는 뜻)

**신호 적중 검증**: 복합 신호가 뜨면 1분/3분/5분 뒤 실제로 그 방향으로 움직였는지 자동으로
추적해서 로그에 "[검증 N분] ... ✅적중/❌불발"로 남기고, 3분 기준 적중률을 로그 패널 상단에
집계해서 보여준다. 기록은 `signal_log.csv`에 누적되니, 어떤 신호 조합이 실제로 쓸만한지
데이터로 판단하는 데 참고할 것. 적중 기준은 ±0.1% 이상 움직였는지로, 애매하게 거의 안 움직인
경우도 "불발"로 카운트됨(엄격한 기준).

**보유 포지션 추적**: 포지션 크기 계산기에서 "→ 포지션 등록"을 누르면(워치리스트에 종목이
정확히 1개일 때만 가능) 현재가가 손절가/목표가에 닿는 순간 알림을 준다 — 이것도 알림만이고
주문은 안 넣는다. 등록된 포지션 종목은 워치리스트에 없어도 자동으로 감시 대상에 추가된다.

**주의**: 종목 수를 늘릴수록 폴링 주기 안에 API 호출이 늘어나 레이트리밋에 걸리기 쉬움
(종목 1개당 폴링 1회마다 2번 호출 — 현재가 + 호가). 워치리스트는 5~10종목 이내를 권장.

## 파일 구성

- `kis_feed.py` — KIS Open API 최소 래퍼 (토큰 발급/캐시, 일봉/현재가/PER/PBR/호가/체결강도 조회, 레이트리밋)
- `dart_feed.py` — DART(전자공시) Open API 최소 래퍼 (부채비율, 영업이익/매출 YoY 등)
- `auto_finder.py` — 스윙 스크리닝 로직 (`run_scan()` 이 `gui.py`에서 호출하는 핵심 함수), CLI로도 실행 가능(`python auto_finder.py`)
- `gui.py` — 대장주 자동 발굴기 Tkinter GUI
- `scalper.py` — 초단타 모니터링 Tkinter GUI (신호 전용, 자동매매 아님)
- `diag_marcap.py` — KRX 시총 데이터 문제 진단용 스크립트

## API 키 준비

- **KIS**: [한국투자증권 Open API](https://apiportal.koreainvestment.com)에서 APP KEY/SECRET 발급 (모의/실전 각각 별도)
- **DART**: [opendart.fss.or.kr](https://opendart.fss.or.kr)에서 무료로 인증키 발급 (필수 아님 — 없어도 KIS 조건만으로 동작)

## 주의

- 추천이 아니라 조건 스크리닝 도구입니다. 매수 여부·종목·금액은 본인 판단.
- 대형주만 대상이며, 종목 수가 많을수록(TOP_N↑) 스캔 시간이 길어집니다(종목당 API 호출 여러 번).
- DART 재무정보는 공시 주기(분기)상 최신이 아닐 수 있고, 일부 종목은 계정명이 달라 조회가 안 될 수 있습니다(이 경우 필터 대상에서 제외하지 않고 통과시킵니다).
