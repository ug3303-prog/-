# 대장주 자동 발굴기 (GUI)

`auto_finder.py`의 스크리닝 로직(대형주 + 상승추세 + 눌림 + 거래대금 + PER/PBR + DART 재무)을
Tkinter 데스크톱 GUI로 감싼 프로그램. 조건 충족 종목 중 **점수가 높은 3종목(추천 후보)** 을 따로 뽑아준다.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python gui.py
```

1. 상단에 KIS(한국투자증권) Open API `APP KEY` / `APP SECRET` 입력 (모의투자면 체크박스 선택)
2. "키 저장"을 누르면 `kis_keys.json`에 저장되어 다음 실행부터 자동 로딩됨 (git에는 커밋되지 않음).
   저장하지 않아도 화면에 입력한 값이 그대로 쓰인다.
3. DART 재무정보(부채비율, 영업이익 흑자여부 등)를 쓰려면 `DART API KEY`도 입력하고
   "DART 재무정보 사용" 체크 — 종목마다 추가 조회가 붙어 스캔이 느려짐
4. 조건 확인 후 "▶ 스캔 시작" (마지막에 쓴 조건값은 `gui_settings.json`에 자동 저장)
5. 결과는 "추천 후보 3종목" / "조건 충족" / "칼날 주의(하락추세)" 표에 표시, CSV로도 저장 가능
   (CSV 상단에 스캔 시각과 조건이 함께 기록됨)

## 추천 후보 3종목은 어떻게 뽑나

조건 충족(대형주 + 200일선 위 + 눌림) 종목 중 아래 **하드 필터**를 모두 통과한 종목만 점수를 매긴다.

| 하드 필터 | 기준 |
|---|---|
| 눌림 | 20일 고점 대비 7% ~ 20% (20%+ 는 악재 의심) |
| 200일선 위 | +3% ~ +60% (너무 가까우면 갓 전환, 너무 멀면 추격 부담) |
| 200일선 기울기 | 20거래일 전보다 상승 중 |
| 거래량비 | 평소의 2.5배 이하 (과열 아님) |
| 이익 | 적자(PER 없음) 제외, DART 사용 시 영업적자 제외 |
| 수급 | 외국인·기관 5일 동반 순매도면 제외 |

점수(100점): 눌림 구간 25 · 추세 20 · 유동성 10 · 거래량 10 · 업종 대비 밸류 15 · 재무 10 · 수급 10.
데이터가 없는 항목(DART 미사용, 업종 표본 부족 등)은 중립 점수를 준다.
상위권만 외국인/기관 수급을 조회해 다시 점수를 매기고, **가능하면 업종이 겹치지 않게** 3개를 고른다.
기준값은 `auto_finder.py` 상단의 `PICK_*` 상수에서 바꿀 수 있다.

## 파일 구성

- `kis_feed.py` — KIS Open API 래퍼 (토큰 발급/캐시/만료 시 자동 재발급, 현재가·PER·PBR·업종·위험 플래그, 투자자별 수급, 레이트리밋)
- `dart_feed.py` — DART(전자공시) Open API 래퍼 (부채비율, 영업이익/매출 YoY 등, 오류 종류별 캐시 규칙)
- `auto_finder.py` — 스크리닝·점수화 로직 (`run_scan()` 이 GUI에서 호출하는 핵심 함수), CLI로도 실행 가능(`python auto_finder.py`)
- `gui.py` — Tkinter GUI (실제 실행 파일)
- `scalper.py` — 초단타 모니터링 GUI (신호 전용, 자동매매 아님 — 아래 '초단타 모니터링' 참고)
- `test_auto_finder.py` — 단위 테스트 (`python -m unittest test_auto_finder`)
- `diag_marcap.py` — KRX 시총 데이터 문제 진단용 스크립트

## 초단타 모니터링 (`scalper.py`)

```bash
python scalper.py
```

**⚠️ 매수/매도 주문을 절대 넣지 않는 읽기 전용 툴입니다.** 워치리스트 종목을 폴링 주기(기본 3초)마다
조회해서 호가 매수/매도 잔량비, 체결강도, 거래량 급증, 급등/급락을 표와 알림 로그로만 보여줍니다.
하단 "포지션 크기 계산기"도 참고용 계산일 뿐 자동 주문이 아닙니다.

- 체결강도 150 이상 = 매수 쏠림, 70 이하 = 매도 쏠림 (100이 균형)
- 호가 총매수잔량/총매도잔량 1.8배 이상 = 매수우위, 0.56배 이하 = 매도우위
- 폴링 사이 ±1% 이상 = 급등/급락, 거래량 증가분이 직전의 3배 초과 = 거래량 급증
- 종목 1개당 폴링마다 2번 호출(현재가+호가) — 레이트리밋 때문에 워치리스트는 5~10종목 권장
- 체결강도·호가 필드명은 아직 실제 KIS 응답으로 확인 전입니다. 값이 늘 비어 있거나 이상하면 알려주세요.

## 자동 생성되는 캐시 파일 (모두 git 제외)

- `.price_cache/` — 종목별 일봉. 재스캔 때 최근 구간만 새로 받는다. 일주일에 한 번 전체 재수집하고,
  겹치는 구간의 종가가 달라지면(액면분할·배당 조정) 즉시 전체 재수집한다.
- `.krx_master_cache.json` — 종목 마스터(시총 등). 하루 한 번 갱신, 다운로드 실패 시 저장된 목록 사용.
- `.last_scan.json` — 직전 스캔 결과. 다음 스캔에서 "신규" 표시와 "이탈" 종목 안내에 쓴다.
- `.dart_*_cache.json` — DART 캐시. 정상 7일 / 공시 없음 1일 / 일시 오류는 저장 안 함.

## API 키 준비

- **KIS**: [한국투자증권 Open API](https://apiportal.koreainvestment.com)에서 APP KEY/SECRET 발급 (모의/실전 각각 별도)
- **DART**: [opendart.fss.or.kr](https://opendart.fss.or.kr)에서 무료로 인증키 발급 (필수 아님 — 없어도 KIS 조건만으로 동작)

## 주의

- 추천이 아니라 조건 스크리닝 도구입니다. "추천 후보 3종목"도 위 규칙으로 계산한 점수일 뿐,
  수익을 보장하거나 매수를 권유하는 것이 아닙니다. 매수 여부·종목·금액은 본인 판단.
- 대형주만 대상이며, 종목 수가 많을수록(TOP_N↑) 스캔 시간이 길어집니다(종목당 API 호출 여러 번).
- **장중(평일 09:00~15:40)에 돌리면** 오늘 봉이 미완성이라 거래량비·평균거래대금·이동평균은 직전 거래일까지 기준으로 계산됩니다(화면에 안내 표시).
- 상장 후 200거래일이 안 된 종목은 200일선을 믿을 수 없어 제외됩니다.
- 금융업(은행·보험·증권 등)은 부채비율이 구조적으로 높아 부채비율 필터에서 면제됩니다.
- DART 증감률은 반기·3분기 보고서에서 누적 금액이 있으면 누적끼리 비교하며(표의 "재무 기준"에 표시),
  전년 동기 값이 0 이하이면 계산하지 않고, 500%를 넘는 값은 기저효과로 보고 `N/M`으로 표시합니다. 적자→흑자는 `흑전`.
- DART 재무정보는 공시 주기(분기)상 최신이 아닐 수 있고, 일부 종목은 계정명이 달라 조회가 안 될 수 있습니다(이 경우 필터 대상에서 제외하지 않고 통과시킵니다).
